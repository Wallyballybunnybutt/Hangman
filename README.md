## Hangman Game
A simple command-line Hangman game built with Python. The program randomly selects a word from a predefined list, and the player attempts to guess the word one letter at a time before running out of attempts.

# Features
* Randomly selects a word from a list of words.
* Allows the player to guess letters through the command line.
* Tracks previously guessed letters.
* Prevents duplicate guesses.
* Displays correctly guessed letters and hides remaining letters.
* Gives the player 6 incorrect guesses.
* Displays a win message when the word is correctly guessed.
* Reveals the word when the player runs out of attempts.

# How to Run
1. Download or clone the repository
2. navigate to the project folder on your terminal
3. run the game on your table using the following command:
python3 hangman.py
